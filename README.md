# Финальный проект 5-го спринта: Автоматизация UI для сервиса «Stellar Burgers»

Проект содержит набор автоматизированных UI-тестов для веб-приложения Stellar Burgers https://stellarburgers.education-services.ru/

# Стек технологий
Python 3
Pytest
Selenium WebDriver

# Структура проекта
locators.py - локаторы веб-элементов интерфейса, сгруппированные по страницам.
data.py - URL-адреса страниц, тестовые константы и генераторы динамических данных ("email", "пароль").
conftest.py - общие фикстуры Pytest (driver - для управления жизненным циклом браузера, registered_user - для предусловия регистрации пользователя).
tests/ - директория с тестами, сгруппированными по функциональности:
    test_registration.py - проверка успешной регистрации и валидации некорректного пароля.
    test_login.py - тестирование авторизации через 4 различные точки входа.
    test_profile_and_navigation.py - переход в личный кабинет и возврат в конструктор по кнопке и по логотипу.
    test_logout.py - проверка выхода из учетной записи.
    test_constructor.py - проверка переключения вкладок конструктора бургеров ("Булки", "Соусы", "Начинки").
.gitignore - исключение служебных файлов кэша (__pycache__, .pytest_cache) и виртуального окружения.
